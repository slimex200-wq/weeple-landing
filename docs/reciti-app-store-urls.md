# RECITI App Store URLs

Use the path-based `weeple.app` URLs for the first RECITI iOS submission.

Privacy Policy URL:
https://weeple.app/reciti/privacy

Support URL:
https://weeple.app/reciti/support

Marketing URL:
https://weeple.app/reciti

Terms:
https://weeple.app/reciti/terms

If `reciti.weeple.app` is configured later, prefer:

https://reciti.weeple.app/privacy
https://reciti.weeple.app/support
https://reciti.weeple.app/terms

The support page must remain public, HTTPS-accessible, and include a working support email before these URLs are used in App Store Connect.
