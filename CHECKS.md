# Checks

## Standard Commands

```bash
npm run build
```

## Visual Checks

- Open the landing page locally and inspect desktop and mobile widths.
- Confirm text does not overlap animation, 3D, screenshots, or sticky sections.
- Confirm all product claims are grounded in source or documented product decisions.

## Before Delivery

- Report which checks ran.
- If a browser check was not run, say that explicitly.
- Do not treat a successful build as proof of visual quality.
